# Wanderly Travel

A one-page site for Wanderly Travel. It is plain HTML and CSS. There is no build step and no JavaScript. A mood picker above the trips uses radio buttons to fade the other cards and rename the plan link.

## Open it

Open `index.html` in a browser.

## Page

The header links jump to sections on the same page:

- **Home** is the hero, with a photo and a link to plan a trip.
- **Packages** lists six tours: Bali, Paris & Provence, the Swiss Alps, Kyoto, Santorini, and Morocco. Each card has a photo, a short description, a three-day outline, the length, and the price. Coast, Mountains, and Culture highlight the matching trips.
- **Testimonials** has three traveler quotes.
- **Plan** is a mailto link to `hello@wanderly.example`. The button names the trips in the selected mood.
